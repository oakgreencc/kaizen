# Report template

Write the report to the `report` path from `K paths`, dating it with `day`. Omit any section with no findings; if there are no findings at all, the whole report is `# Kaizen report <day> — no findings.`

```markdown
# Kaizen report <day>

Sessions analysed: <N> (<M> skipped: <self-referential / no human text / resumed counts from extract>)
Projects: <comma-separated>
Window: <earliest started> → <latest ended>

## Memories

- **<slug>** (new | updated | proposed) — <rule>. Seen in: *<title>* ("<quote>"), *<title>* ("<quote>").

## Proposed user-level instructions

- <one line for ~/.claude/CLAUDE.md> — seen across <projects>: *<title>*, *<title>*.

## Corrections

- **<project> — <title>** — <what was corrected and why>.

## Quality gaps

- **<project> — <title>** — <what was missed>.

## Convention misses

- **<project> — <title>** — <the rule and where it lives>.

## Friction

- **<pattern>** — <description>. Sessions: *<title>*, *<title>*.

## Scripts that should be permanent

- **<task>** — seen in *<title>*, *<title>* (<languages>; <recurrence | iteration | load-bearing>). Proposed home: `<path>`.

## Observations

<cross-cutting themes, positive patterns, ideas for new skills or conventions>
```

Tone: specific (name the session and the behaviour), constructive (a finding is an improvement to make), brief.
